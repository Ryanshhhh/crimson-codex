赤典 (CRIMSON CODEX) — 使用者線上操作指南
歡迎來到 [ 赤典 CRIMSON CODEX ] 的意識空間。這是一款專為創作者、設計師打造的純單機版沉浸式視覺素材看板。本工具採用完全獨立、零後端、數據 100% 本機內化的去中心化架構，保障您靈魂深處的創意隱私。

儀式啟動 (The Awakening)
當您初次開啟「赤典」，畫布中央的巨大神祕圖騰（瞳孔之眼），靜靜等待您的靈感。

畫布核心操作 (Canvas Mechanics)
1. 空間移動與視差
• 畫布平移：在畫布任意空白處，按住滑鼠左鍵/觸控板不放並拖曳，即可無限延伸您的畫布空間。
• 畫布縮放：使用滑鼠滾輪或觸控板雙指開合，即可放大（檢視細節）或縮小（掌握大局）。

2. 素材置入與分類標籤
• 圖片卡片：直接從您的 Mac/PC 桌面，將任何圖片拖曳（Drag & Drop）進畫布中。
• 文字圖卡：在畫布任意空白處「雙擊滑鼠左鍵」，即可在該位置創立一張文字卡，可直接在卡片內雙擊編輯純文字備註。
• 多層級五色調色盤：
	• 將滑鼠懸停在圖片下方的 [ 標籤 ] 上（文字卡則是直接懸停在卡片上），會浮現極簡的選色選單。
	• 共有五種嚴格控制低飽和度的高質感神祕暗調供點選切換：
		• 🔴 CRMS (Mystic Crimson 暗紅調)
		• 🟣 CYBR (Cyber Violet 暗紫調)
		• ⚪ OBSDN (Obsidian Grey 曜石灰)
		• 🟢 ABYSL (Abyssal Teal 暗青調)
		• 🟡 AMBR (Smoky Amber 暗琥珀)

3. 建立靈感連結與聚焦邏輯
  • 關聯連線：從圖片/文字卡片的邊緣圓點，可以拉出白色虛線（端點為實心圓點）連接到另一張卡片。雙擊連線中央的標籤文字可為這條分支命名。
	
為了極致提升操作效率，請熟記以下鍵盤秘籍（亦可隨時點擊畫布左下角的 Cheatsheet 面板對照）：
功能動作	Mac 系統快捷鍵	Windows / Linux 快捷鍵

一步重做 (Redo)	⌘ + ⇧ + Z 或 ⌘ + Y	Ctrl + ⇧ + Z 或 Ctrl + Y

刪除選中項目 (卡片/連線)	Delete 或 Backspace	Delete

10px 大幅移動選中卡片	Shift + 方向鍵	Shift + 方向鍵

資料管理與隨身攜帶
赤典將所有資料保存在使用者的瀏覽器快取中，為防止資料遺失，請妥善利用左側側邊欄的控制面板：
• ＋ 新增畫布 (New Canvas)：點擊側邊欄頂端，可開立完全獨立的全新畫布空間，並自由命名。
• 匯出專案檔案 (Export Data)：一鍵將當前所有多畫布結構、文字、連線，以及畫布上的圖片下載為單一的 .json 檔案。
• 匯入專案檔案 (Import Data)：在任何人的電腦打開相同的赤典網頁，點擊匯入此 .json 檔案，即可 100% 完美復原整面靈感牆，絕不破圖、絕不遺失圖片。
